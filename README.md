# MoneyApp
Application for Money Track

## Onboarding app

The mobile onboarding flow lives in [`app/`](app/) (React + Vite + TypeScript). See [`app/README.md`](app/README.md).

**Try it:** https://ezequielballesteros95.github.io/MoneyApp/. Open it on your phone and use "Add to Home Screen" to install it like an app. Every push to `main` redeploys it via `.github/workflows/deploy.yml`.

```sh
cd app && npm install && npm run dev
```
